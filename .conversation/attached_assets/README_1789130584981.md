# Speech-to-Text Production Pipeline

High-performance, production-grade Speech-to-Text API powered by `faster-whisper`, `FastAPI`, `Silero VAD`, and `FFmpeg`.

## Features
- **CTranslate2 Acceleration:** Uses `faster-whisper` for fast inference using CUDA `float16` or CPU `int8`.
- **In-Memory Audio Streaming:** FFmpeg subprocess piping processes MP3, WAV, M4A, FLAC, and WebM streams without local disk writes.
- **Voice Activity Detection (VAD):** Integrated Silero VAD strips silent intervals to prevent model hallucinations and reduce processing time.
- **Timestamp Precision:** Outputs segment-level and word-level timestamps.
